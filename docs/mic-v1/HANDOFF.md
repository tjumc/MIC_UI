# MIC 版本 1：内容迁移与学校交付

## 范围和入口

- 新站入口：`dist/mic-v1/index.html`；英文入口：`dist/mic-v1/en/index.html`。
- 在项目根目录运行 `python3 src/mic_v1/build.py` 生成静态站点；内容集中在 `src/mic_v1/data/content.json`，不需要 Node 或服务端运行时。运行 `python3 src/mic_v1/test_migration.py` 和 `node src/mic_v1/test_interactions.js` 检查生成结果。
- 基于导师认可的方案一；三套原方案、原设计分支、主分支和既有预览均未被替换。新站使用独立路径和分支。
- 原站资料快照采集于 2026-11-25。内容包括中英文团队、17 条成员、62 条校友、46 条历史课程、236 条论文、45 个论文项目页、14 个原站研究专题，以及两篇 2022 年招生通知正文。招生通知与课程、校友去向均以历史资料标示；论文保留原站列出的年份和发表状态。
- 顶部只有一个团队入口，内部保留教师、成员与校友。新增杜杉杉和吴秀哲仅保留姓名，未补写职称、简介或研究方向。
- 五个现行方向按照课题组提供的名称展示；原站“信息编码”说明可追溯，其余新方向的具体介绍需课题组提供。原站 14 个研究专题单独保留，不推断其与新方向的归属关系。

## 内容与资源清单

- `old-url-map.csv`：实际旧 URL 与新页面路径。生成的 68 个 `.htm` 文件是静态兜底跳转，不能替代经站群管理员确认的 HTTP 301/302 规则。
- `image-inventory.csv`：原站 268 条图片引用位置的去重清单（含项目插图、教师照片、地图和首页背景）；除已授权沿用的校标和 MIC 徽章外，图片区域仍保留文字留白，不包含这些图片文件。
- `attachment-inventory.csv`：48 个原站附件地址及引用页面。当前网页保留原站附件直链，不包含附件实体；学校迁移前必须备份附件、上传到学校系统并替换链接。常规 HEAD 返回 403，范围 GET 检查可用；具体状态应在交付时重新核验。
- 英文页面的历史招生说明为工作译文，并保留中文原文供核对；原站英文教师资料和中文资料存在时间性差异，须由课题组核对。
- 论文、正文和项目文字来自原站快照；原站列有出版物使用说明。公开复制论文全文、图表或第三方数据前，应由课题组核实相应授权。

## 可复现的附件备份和打包

`src/mic_v1/data/attachment-check-20261125.json` 记录 48 个附件的旧地址、抽样检查结果与当时大小。二进制附件不进入 Git 设计分支。需要重新准备时，先选择不存在的备份目录：

```sh
python3 src/mic_v1/backup_attachments.py --output /path/to/new-attachment-backup
python3 src/mic_v1/make_handoff.py --attachments /path/to/new-attachment-backup --output /path/to/MIC-v1-handoff.zip
```

备份脚本只保存原始 ZIP、GZ、PDF 文件，不展开或执行；打包时逐个核对字节数和 SHA-256，将可用附件链接改为交付包内的相对地址。大小变化、权限变化或下载失败时应重新核验来源，不要强行跳过。

## 上线前核实

1. 与网站管理员确认站群系统入口、账号、栏目管理方式和测试环境；取得当前模板规范、动态栏目标签、允许上传的附件类型与大小限制。
2. 确认学校希望采用静态站点、模板移植或内容导入；检查无脚本情况下的论文与名单是否可读，评估检索脚本的支持情况。
3. 按 `old-url-map.csv` 配置旧地址对应与服务器级跳转；确认根目录语言默认值、子路径、HTTPS、移动端、中文编码、附件下载及外链。
4. 课题组复核成员、教师职称与履历、五个研究方向、项目与论文发表状态、课程安排、招生规则、联系人和地图；确认图片选择与使用权限。
5. 在学校测试环境核对页面、资源、菜单、中英文切换和旧链接。当前执行环境缺少浏览器操作能力，真实桌面及手机视觉检查尚未完成。

## 切换和回退清单

1. 切换前由学校管理员备份现有站群模板、栏目配置、正文、附件、访问控制、域名与跳转规则，并记录可恢复版本和负责人。
2. 先在独立测试地址导入并核验，保留旧站；经课题组和学校确认后，再由有权限的管理员安排切换。
3. 如切换失败，由管理员恢复原模板、栏目、附件和跳转配置，并核对原首页、招生公告、论文项目和附件可访问性；必要时恢复先前域名解析。
4. 本次工作没有登录、替换或发布到同济正在运行的学校官网。
